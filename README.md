# Velocity Warranty 2026: slide deck

A 20-slide HTML presentation summarizing the *Velocity Motors Warranty Guide, 2026 edition* (a fictional brand used for training).

**Live:** https://varoonsahgal.github.io/velocity-warranty-slides/

## Controls
- `→` / `Space` / swipe left: next slide · `←` / swipe right: previous slide
- `O`: overview grid (click a slide to jump to it) · `F`: fullscreen
- Link to a slide with `#n`, e.g. `#10`
- On the quiz slides (17–18), click a card to reveal the answer.

No build step: plain HTML, CSS and JS. Photos come from Wikimedia Commons; see [credits.html](credits.html).
